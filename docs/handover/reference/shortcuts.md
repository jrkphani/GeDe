# Keyboard shortcuts — matches iCloud Numbers

Resolve every shortcut from `event.code`, not `event.key`, so they work on
Tamil99, InScript and Remington layouts. No shortcut may be the only route to a
command; each also appears beside its command in a menu or tooltip.

## Document
| Action | Keys |
| --- | --- |
| New workscape | ⌘N |
| Open | ⌘O |
| Print | ⌘P |
| Close document | ⌘W |
| Show shortcut sheet | ? |

## Edit
| Action | Keys |
| --- | --- |
| Undo / Redo | ⌘Z · ⇧⌘Z |
| Cut / Copy / Paste | ⌘X · ⌘C · ⌘V |
| Paste and match style | ⌥⇧⌘V |
| Select all | ⌘A |
| Delete contents | ⌫ |

## Find

| --- | --- |
| Find | ⌘F |

| --- | --- |
