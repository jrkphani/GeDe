01 · Visual identity

The mark and what it means

GeDe is generic design: structure that emerges from ordinary text. The mark is a single lattice cell — the grid that underlies every GeDe document — with one filled node showing the cell in focus. It is geometric, drawn on an 8-unit grid, and never illustrative.

Clear space & minimum size
  • Clear space on all sides = the height of one lattice division (¼ of the mark).
  • Minimum mark size 20 px; below that use the filled-node glyph alone at 16 px.
  • Wordmark and mark lock up at a 12 px gap; never re-space the letterforms.
Never
  • Recolour the node in the selection amber — the mark is brand, not state.
  • Place the green mark on a mid-tone photo; use the reversed white mark.
  • Rotate, outline, add a shadow, or set the wordmark in another face.

02 · Colour

Two hues, one job each

Forest #14532d is the brand: identity, primary actions, links, the active state of navigation. Amber #b45309 is live state: the selected cell, formula references, collaborator presence, unsaved and in-progress. Keeping them apart means a user never has to ask whether a green thing is a brand element or a selection.

Rules
  • Forest 700 on white is 10.6:1 — safe for body text, not only headlines.
  • Amber 700 on white is 4.8:1 — safe for text; amber 500 is decoration only.
  • Never use hue alone to carry meaning: pair with an icon, label or weight.
  • Surface tints step by one ramp value; no arbitrary alpha overlays.
  • Dark theme is a token swap, never a filter or invert().
03 · Typography

One grotesque, one mono

Helvetica Neue for interface and content; IBM Plex Mono for anything addressable — cell references, formulas, tokens, counts, labels. The mono face is a signal, not a style: if it is monospace, you can type it into a formula. Indic scripts fall back to Noto, which Helvetica does not cover.

04 · Space, radius, elevation

A 4 px base and a 160 × 22 lattice

Interface spacing steps in 4 px units. The document canvas is separate and absolute: a 160 × 22 px lattice that gives every cell its A1 address. Never mix the two — canvas objects snap to the lattice, chrome pads on the scale.

05 · Iconography

Drawn, not decorated

One family, one construction. Icons are line-drawn on a 18 × 18 grid at 1.3 px stroke, sharing the mark's geometry: square frames, 4-unit corner radii, filled circles for nodes. They label actions the interface cannot afford to spell out — never decoration, never a substitute for a word when space allows one.

Construction
{{ iconGrid }}
  • 18 × 18 viewBox, 1 px keyline inset, 16 px live area.
  • Stroke 1.3 px, round caps and joins, no fills except nodes.
  • Corner radius 1.6 px on small frames, matching the mark at scale.
  • Optical alignment beats mathematical centring — nudge to look right.
Sizes
{{ iconSizes }}
  • 13 px inside dense chrome and menus · 15 px default · 18 px on primary toolbars.
  • Stroke stays 1.3 px at every size; never scale the stroke with the box.
  • Hit area is always ≥ 32 px, ≥ 44 px below the lg breakpoint.
Colour
{{ iconColours }}
  • Icons inherit currentColor; never hard-code a hue in the path.
  • Ink 900 at rest, forest when the state they control is active, amber when it is live.
  • Disabled is slate 400, not opacity — opacity muddies against tinted rows.

Do
  • Pair an icon with a label wherever the toolbar has room.
  • Give every icon-only control a tooltip and an aria-label.
  • Reuse an existing icon before drawing a new one; a near-duplicate is worse than a reused approximation.
  • Keep one meaning per glyph across the whole product.
Don't
  • Mix filled and outline styles in one surface.
  • Use emoji, an icon font, or a third-party set with a different construction.
  • Let an icon carry a state alone — pair it with colour, position or text.
  • Draw anything pictorial: no illustrations, no mascots, no skeuomorphism.

06 · Components

Atoms to organisms

Every specimen below is the real component. Interact with them — hover, focus with the keyboard, click. States are not illustrated, they are live.

Build on a library, not on hand-rolled primitives. Behaviour — focus traps, roving tabindex, portal positioning, ARIA wiring, dismiss semantics — comes from a headless library (Radix UI, or Ark/Base UI). GeDe supplies only tokens and skin. A hand-rolled dropdown is a defect: it will be inconsistent, and it will be inaccessible.

07 · Responsive

Five breakpoints, one layout law

Chrome adapts; the document does not reflow. A table keeps its lattice geometry at every size — the viewport moves over it. What changes is how much chrome surrounds it and whether editing is offered at all.

TokenRangeChromeCapability
{{ b.token }} {{ b.range }} {{ b.chrome }} {{ b.cap }}
Do
  • Query the container, not the window, for anything inside the canvas.
  • Collapse the inspector to a 38 px strip before you shrink its contents.
  • Let toolbars wrap to a second row rather than clip or scroll horizontally.
  • Raise hit targets to 44 px below md; pointer is coarse there.
Don't
  • Reflow a table's columns at a breakpoint — addresses would change.
  • Hide a command with no other home; move it, or state that it is unavailable.
  • Ship an edit affordance below md; phone is read-only by contract.
  • Scale type with vw; it breaks user zoom.
08 · Motion

Physics, briefly

Motion explains where something came from. Nothing moves for decoration, nothing animates longer than 300 ms, and every transition is cancellable. Hover the swatches to run each curve.

10 · Developer handoff

Tokens are the contract

One source of truth in JSON, emitted as CSS custom properties and a typed TypeScript theme. Components read tokens; they never carry literal colours or sizes. A hex code in a component file fails review.

{{ codeBody }}
Naming
  • category-role-variant-state, kebab in CSS, camel in TS.
  • Primitives (forest-700) are private; components use semantic aliases (action-primary-bg).
  • Figma styles carry the same names, so a design change maps to one token.
Definition of done
  • No literal colour, radius, or duration in component source.
  • All five states specified and reachable by keyboard.
  • Renders correctly at 480, 768, 1024, 1440 and at 200 % zoom.
  • Light and dark both checked; contrast recorded in the PR.
  • Built on the headless primitive, not on a div with handlers.
11 · Voice and notifications

Say the thing

Voice
  • Plain, specific, unhurried. No exclamation marks, no "Oops", no emoji.
  • Name the object: "Delete Work-Force?" not "Delete this item?".
  • Buttons are verbs — Share, Invite, Delete — never OK / Yes / Submit.
  • Errors state cause and remedy: "Sum skipped D14 — it holds text."
  • Sentence case everywhere. Title Case only in the wordmark.
Email rules
  • Subject ≤ 60 characters, front-loaded with the actor or object.
  • One primary action per message; a plain-text link beneath it.
  • Sender GeDe <no-reply@gede.1cloudhub.com>; reply-to the actor where one exists.
  • Never include document content — the recipient may not have access.
  • Codes expire in 10 minutes and say so; invitations in 14 days.
