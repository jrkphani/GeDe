TURN 1 · FIRST-RUN GUIDE

Two ways to run the 90-second pass

Both work the same sample workscape, Q3 Delivery, which is seeded into every library at first login and stays there — resettable, never deleted. Both cover the same four steps, performed for real: cross-table reference, context graph, workscape-wide find, invite by email. Both skip what Numbers already teaches. They differ in who holds the pace.

1A Coachmarks — the tour drives

One spotlight at a time, scrim over everything else, a numbered card anchored to the target. The step only advances when the action is actually performed. Fastest to a finish, most interruptive; Skip is always in the card.

1B Checklist rail — the user drives

A docked rail lists the four tasks; the active one expands with its copy and a “Show me where” that flashes the target. Nothing is blocked, tasks tick themselves as the user does them, and the rail collapses to a pill. Slower, but survives a user who wanders off mid-tour.
