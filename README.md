# GeDe

GeDe is a text-oriented spreadsheet on an infinite lattice: tables, rich text, formulas, cross-table references and context graphs on one shared, real-time canvas. Every cell has a computed A1 address because the canvas is the grid; text is the primary datum and string operations are first-class.

This repository is the v2 rebuild (September 2026). v1 is archived at branch `archive/v1`, tag `v1-final`, and is not a reference for anything here.

## Layout

| Path               | What it is                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| `apps/web/`        | React 19 + Vite SPA. Radix primitives via `@gede/ui`. Reads `/config.json` at runtime.                |
| `services/sync/`   | Fastify + `ws` (y-websocket protocol) + REST. Verifies Cognito JWTs. Persists to Postgres + S3.       |
| `packages/core/`   | Framework-free domain: lattice index, A1 addressing, dependency graph, formula grammar, text algebra. |
| `packages/tokens/` | `tokens.css` + `theme.ts` from the handover, plus the "no literal hex/px/ms" lint check.              |
| `packages/ui/`     | Design-system components on Radix. Icon sprite.                                                       |
| `packages/db/`     | Drizzle schema, numbered SQL migrations, migration runner.                                            |
| `infra/`           | One CDK app: `PipelineStack` + `GedeStage` (Network, Data, Auth, Edge, Service, Web, Dns, Ops).       |
| `docs/`            | Requirements, architecture, runbook, decisions, traceability, and the handover package.               |
| `scripts/`         | Repo tooling (traceability generator).                                                                |

Each package with its own conventions has a `CLAUDE.md`; read it before editing that package.

## Quick start

Requires Node 22 (`.nvmrc`) and npm 10.

```bash
npm ci              # install every workspace
npm run verify      # typecheck + lint + format:check + unit tests (what CI runs)
npm run dev         # web dev server; needs apps/web/public/config.json and the sync service on :3000
npm run build       # all workspaces
npm run synth       # cdk synth (infra)
npm run e2e         # Playwright journeys + axe against a built bundle (no backend; docs/TESTING.md)
```

See `apps/web/CLAUDE.md` for local config and `services/sync/CLAUDE.md` for the environment variables and a local Postgres.

## Delivery model

`main` is production. Every merge to `main` runs CodePipeline `GeDe` in `ap-southeast-1` (AWS account 975049998516):

```
Source (GitHub, main) → Synth (npm ci, npm run verify, build web, cdk synth) → SelfMutate
→ Assets (arm64 image, web bundle) → Prod stage (8 stacks) → Smoke (/healthz, homepage)
```

Failures roll back through the ECS deployment circuit breaker and CloudFormation. Nobody runs `cdk deploy` from a laptop after the one-time bootstrap. Work on branches, open a PR with the template, name the requirement ids the PR closes, squash-merge.
